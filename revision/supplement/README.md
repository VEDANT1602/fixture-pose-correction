# Planar fixture registration sensitivity

The original simulator, its 162-row result table and its arithmetic verifier are pinned at https://github.com/VEDANT1602/fixture-pose-correction/tree/be91e32b7e57c2c81a5308da8345031aa1474588 . Run `python run.py` then `python verify.py` in that checkout. The main manuscript tables use that experiment (seed 1705).

`fixture_sensitivity.py` is a separately written simulator for the revision. Run `python fixture_sensitivity.py` in this folder. Its outputs overwrite the two local CSVs. `independent_results.csv` contains 162 condition-policy aggregates for an additional 1,000 fixtures per regime (seeds 51705 and 51706). `sensitivity.csv` uses 10,000 new challenge fixtures from seed 71354 with common draws across all 27 combinations of span, independent localization noise and assumed yaw spread. The nominal 0.45 mm noise in the estimator is held fixed. Each row compares shrinkage to full rotation under the same observations. The paired standard error, in percentage points, is 100 times the sample standard deviation of the paired binary differences divided by the square root of the number of fixtures. Rows share draws.

All positions and times in the fixture simulations are generated. The independent photographed-board study below uses actual image measurements. The original published snapshot lists NumPy 1.26.0. The revision computational environment for both the original and added checks was Python 3.12.14 and NumPy 2.3.5. To match the extension run use the accompanying requirements file. The fixture simulations require no external observations.

## Environment lock

Create separate Linux x86_64 virtual environments with CPython 3.12.14 for the revision and 3.11.9 for the baseline. In the activated revision environment run `python -m pip install --require-hashes -r revision-cp312-linux-x86_64.lock`. For the original checkout, install `baseline-cp311-linux-x86_64.lock` the same way in the baseline environment, then run the commands above. Apply the baseline lock in the pinned public checkout, and the revision lock when executing fixture_sensitivity.py. The lock headers identify the platform; the baseline transitive pins reconstruct a compatible environment for the published direct requirements.

## Registration alternatives and serial fixtures

Run `python registration_baselines.py` in the revision environment. Each of 100 independent trajectories includes 100 fixtures, sharing yaw innovations and marker/endpoint/recovery draws across policies. Calibration seed 33108 supplies 600 independent poses with two images per pose. Evaluation seed 515194 supplies the two serial regimes. Use `baseline_comparison.csv` for all 90 condition-policy summaries and `baseline_by_sequence.csv` for the paired differences of each trajectory from least-squares rigid correction. The maximum absolute SVD-versus-direct yaw discrepancy is stored on each summary row. At matched .45 mm noise, recompute the paired temporal-minus-adaptive comparison by subtracting the adaptive trajectory differences from the temporal trajectory differences, then calculate the standard error across 100 sequences.

## Measured checkerboard comparison

Run `python board_check.py` against the included derived coordinates to regenerate `board_spans.csv`. It uses the default revision NumPy environment. Every `board_corners.csv` row records the image filename, SHA-256, nominal board indices and subpixel image measurement. There are 13 photographs × 54 measured intersections. Two interior rows and three symmetric marker spacings yield 78 paired chord rows. Angular residuals use degrees. The target residuals use board-square units.

To regenerate the coordinates from original photographs, create a separate CPython 3.12 Linux x86_64 virtual environment, install `python -m pip install --require-hashes -r source-extraction-cp312-linux-x86_64.lock`, and run `python board_check.py --extract /path/to/image-cache`. If needed this downloads the 13 numbered images from the pinned OpenCV source. It uses OpenCV 4.12.0.88 and NumPy 2.2.6. The extraction was rerun in that compatible environment. The photographs remain available upstream; only the measured point coordinates and derived summaries are included here.
